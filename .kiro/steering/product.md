# Product: MAZNET ISP Management System

MAZNET is a full-stack ISP (Internet Service Provider) management platform for a company called MAZNET. It combines a public-facing landing page with a multi-role admin dashboard, Telegram bot integration, Mikrotik network monitoring, and a ticketing system.

## Core Capabilities

- **Public Landing Page** — Hero, about, coverage areas, service packages, blog, contact form, testimonials. Dark theme with glassmorphism and Framer Motion animations.
- **Admin Dashboard** — Multi-role (6 roles: administrator, admin, cs, marketing, editor, teknisi) with role-based sidebar navigation, CRUD for all entities, and activity logging.
- **Multi-Bot Telegram** — Multiple bots with per-bot AI toggle, long polling or webhook mode, 5-state conversation state machine (ticket creation, bandwidth upgrade, new installation, talk to CS, idle), 6-hour cooldown system.
- **AI Integration** — Multi-provider support: OpenAI, Gemini, Claude, OpenRouter, Custom API (Ollama/vLLM). Per-bot toggle, 10-message history context, 20s timeout.
- **Ticketing System** — 4 types (maintenance, upgrade, installation, request), 4 statuses, 3 priorities, inline assignment, role-based visibility.
- **Mikrotik Network Monitor** — RouterOS API integration, real-time traffic charts (Recharts), PPPoE sessions, router logs.
- **Blog** — TipTap WYSIWYG editor, featured images, tags, excerpts, slugs, author tracking.

## Target Users

- ISP company staff (admins, CS agents, technicians, marketing, editors)
- End customers (via public landing page and Telegram bot)

## Language

The product is Indonesian-language (Bahasa Indonesia). UI text, comments, and content are primarily in Indonesian.
