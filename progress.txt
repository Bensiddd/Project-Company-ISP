## TELEGRAM BOT SYSTEM

### Multi-Bot Architecture
- Multiple bots per admin, each with own token/role/AI config
- Role: admin (notifikasi), customer_service (polling + AI), teknisi
- Auto-start polling for all active customer_service bots on server start
- Polling interval: 2 seconds
- Webhook support (auto-stop polling)

### State Machine
| State | Trigger | Next State |
|-------|---------|------------|
| idle | "🎫 Buat Ticket" | awaiting_ticket_description |
| idle | "📶 Upgrade Bandwidth" | awaiting_upgrade_customer_id |
| idle | "🔧 Instalasi Baru" | awaiting_install_address |
| idle | "💬 Bicara dengan CS" | human mode |
| awaiting_ticket_description | user text → create ticket | idle (main menu) |
| awaiting_upgrade_customer_id | user text → show packages | awaiting_upgrade_package |
| awaiting_upgrade_package | user selects → create upgrade ticket | idle |
| awaiting_install_address | user text → ask location | awaiting_install_location |
| awaiting_install_location | text/GPS → create install ticket | idle |
| any | "menu" or "batal" | idle (main menu) |

### Inline Keyboard Menu
```
🎫 Buat Ticket        📶 Upgrade Bandwidth
🔧 Instalasi Baru     💬 Bicara dengan CS
```

### Location Support
Telegram location messages converted to Google Maps link in ticket description.

- Max 500 tokens output
- Timeout 15 detik (AbortController)
- Error handling per provider
